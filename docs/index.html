How it works

  • Data. Results and bookmaker odds since 2000/01 (football-data.co.uk); fixtures and injury flags from the official Fantasy Premier League API. Refreshed on every build.
  • Features. Elo rating with home advantage, last-5 form, goals and shots on target for and against, home-only and away-only form, rest days. All built from matches before kickoff, so there is no peeking at the future.
  • Models. Multinomial logistic regression and XGBoost, blended.
  • Benchmark. Bookmaker odds with the margin removed. Beating them consistently with public data is not realistic; getting close is.
  • Limitation. Injuries are shown as context but are not a model input yet: the feed only shows who is injured now, so there is no history to train on. Daily snapshots are being saved so this can change.
